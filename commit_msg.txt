feat(core): Chronos PnL accuracy, Backtest UI Trades Export, Sentinel Min DTE logic

This commit consolidates critical mathematical fixes to the backtest engine and introduces crucial constraints to the Sentinel orchestration UI, alongside a fully reconstructed trades reporting table.

### 1. Chronos Mathematical Accuracy & Expiry Logic
- **`chronos.py`**: Fixed a massive compounding bug where premium received on `SELL` trades was erroneously added back into capital at entry while also being tracked in PnL, causing infinite capital scaling (e.g. 600-billion trades).
- **Expiry Proximity Filtering**: Chronos now simulates `next_expiry` properly using the active backtest date rather than `datetime.now()`. Added a strict mathematical buffer (`max_days = min_days + 10`) that actively prevents backtesting highly-inflated month-out options if the real weekly option data is not available.

### 2. Sentinel DTE Configuration
- **`models.py` & `program_manager.py`**: Expanded the `SentinelGroup` schema to allow configuration of `min_working_days_to_expiry`. Orchestrator now correctly passes this down into dynamic spawn payloads.
- **`frontend/programs.js`**: Rebuilt the Sentinel creation form to parse execution modes (`paper` vs `live`) and display the Min DTE numeric constraints explicitly.
- **Paper Styling**: Dynamic styling matches Advanced OMS. Sentinel Groups in "paper" mode now correctly render with an amber background and a designated "PAPER" UI badge.

### 3. Backtest Report UI & Data Export
- **Trades Table**: The Chronos backtest UI was upgraded from simple "events" to full trade analysis. The grid now accurately reflects mathematical Max Drawdown.
- **`exportBacktestTradesCsv`**: Reintroduced the `CSV Export` button directly in the modal, which exports highly detailed trade-by-trade analytics including `Capital Deployed`, `Script(s) traded`, `Entry/Exit timestamps`, and absolute `PnL`.
- **WebSocket Streaming**: Fixed JSON stringification that caused the `[object Object]` bug, restoring precise percentage loading updates onto the user interface.

### 4. Tradejini API Rate-Limit Resilience
- **`tradejini_client.py`**: Intercepted Tradejini's `get_scrip_groups` and injected local caching. ScriptMaster now detects if `isUpdated=True` matches today's date, blocking redundant gigabyte-sized CSV re-downloads on every app startup. Added JSON disk caching for historical minute-interval charts to drastically speed up multi-run backtests.

All architectural implementation plans and code validations are logged durably in `agent-actions/`.
