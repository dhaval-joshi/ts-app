feat(core): Phase 1 complete - Chronos, Sentinel, ORB Signals & BSM Greeks

This is a massive consolidation commit covering multiple Iterations from the Unified Framework (up through Iteration 1.4 Overlord). It brings full backtesting capabilities, live indicator tracking, and fully autonomous regime-aware orchestration.

### 1. Chronos Backtesting Engine & BSM Calculator
- **`chronos.py`**: Added a native backtesting engine that simulates minute-by-minute order execution against historical OHLCV data. Fixed cyclic websocket imports that previously crashed the simulation on the first trade.
- **`bsm_calculator.py`**: Introduced a pure mathematical Black-Scholes model utilizing the Newton-Raphson method to reverse-engineer Implied Volatility (IV) and calculate Delta, Gamma, Theta, and Vega from historical tick data.
- **Dependencies**: Added `numpy` and `scipy` for CDF/PDF standard normal distribution functions.

### 2. Autonomous Sentinel & The Orchestrator (Iteration 1.4 Overlord)
- **`sentinel_orchestrator.py`**: Completely overhauled Sentinel Groups to dynamically rotate capital between mutually exclusive child programs (`SIDEWAYS`, `DIRECTIONAL`, `VOLATILE`).
- **Autonomous Mode**: Decoupled static configuration limits. The engine now uses `autonomous_sentinel` execution mode to directly obey the global Regime Classifier and bypass manual entry gates.
- **Admin UI Decoupling**: Moved the global Sentinel Settings (ADX period, ATR threshold) out of the main Cockpit dashboard and into a secure `/admin` panel to prevent accidental overrides during volatile trading.

### 3. ORB Breakout Signal Engine & Live Indicators
- **`signal_engine.py`**: Created a live L1 streaming processor that tracks N-minute Opening Range Breakouts (ORB) on underlying indices to trigger single-leg option entries unconditionally on breakouts.
- **`indicators.py`**: Added bootstrapping mechanisms to pull historical index data from Tradejini on startup (handling MS/S epoch offsets) to immediately prime Squeeze metrics, VWAP, RSI, and EMA models.

### 4. Manual Single-Leg Options Trading
- **`program_manager.py`**: Implemented `start_manual_single_leg_cycle`, allowing traders to leverage 100% of a program's configured capital on a single directional (CE or PE) leg, ignoring standard paired short-straddle auto-tick cycles.
- **UI Enhancements**: Added manual entry mode toggles to the frontend, parsing indicator statuses directly onto active cards.

### 5. Architectural Cleanups
- Removed outdated static JSON configurations from Sentinel Groups in `models.py`.
- Pushed Handover artifacts tracking all changes to `agent-actions/coded/` and `agent-actions/planned/`.
