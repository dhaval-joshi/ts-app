# Feature request template

Copy this, fill it in, paste it as your message (or use `/new-feature`
in Claude Code, which wraps this same intake automatically).

---

**What I want:** (the feature, in plain terms)

**Why:** (what problem this solves, or what's currently annoying/missing
— this matters more than it might seem: several features in this
project's history got a better design once the underlying "why" was
clear, rather than building exactly the first literal ask)

**Where this fits:** Regular OMS / Advanced OMS / both / neither
(admin, README, something else)

**Is this urgent/safety-related, or can it wait:** (be honest — this
project treats anything touching real order placement, exits, or P&L
accuracy as top priority; a UI polish item is not the same tier)

**Anything you already know about how it should work:** (exact field
names, exact UI placement, specific values/defaults — the more specific,
the less back-and-forth needed)

**Should this be built now, or just documented in the README's roadmap
for later:** (this project has a real, working pattern of writing up a
design in README Section 9 without building it yet — say explicitly
which you want)
