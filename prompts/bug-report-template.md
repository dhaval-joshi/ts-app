# Bug report template

Copy this, fill it in, paste it as your message. The most useful bug
reports across this project's whole history included a screenshot and a
precise description of what was actually observed vs. expected — vague
descriptions ("it's not working right") took much longer to root-cause
than specific ones.

---

**What I did:** (the exact action — clicked X, created a Program with Y
config, etc.)

**What I expected:** (be specific — not just "it should work")

**What actually happened:** (be specific — exact status shown, exact
values displayed, exact error if any)

**Screenshot or copied text of what's shown:** (attach if at all
possible — several real bugs in this project were only fully understood
once a screenshot showed the exact wrong state)

**When it happened:** (market hours or after close? during a specific
action like closing a cycle? does it happen every time or intermittently?)

**How confident are you this is a bug vs. expected behavior you don't
understand yet:** (fine to say "not sure" — but say so, don't guess)
